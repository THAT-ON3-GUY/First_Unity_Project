# Overview

As a software engineer, I wanted to learn about Unity and how to apply my C# skills to games and Game Frameworks. This was my first time creating a game and using Unity and it was interesting to see how my programming knowledge could apply in a different setting. Learning to combine scripts with game objects was very fun.

## About the Game

**[Orb Sumo]** is a game where the player tries to survive against an increasing number of enemies without falling off a platform.

You play as an orb sitting on a floating island as you try to evade enemies and use powerups to knock them off.

## How to Play

**Objective:** Survive

**Controls:**

| Action | Key / Input |
|--------|-------------|
| Move | `W` `A` `S` `D` |
| Jump | `Space` |


**Mechanics:**
* Collect powerups to increase knockback
* Hit enemies or dodge enemies to make them fall
* If you fall off the platform you lose

## Purpose

I wrote this software to learn the fundamentals of game development and the Unity engine. My goals were to:
* Understand Unity's editor, scenes, GameObjects, and component-based design
* Write C# scripts to handle player input, movement, and game logic
* Work with Unity's physics system, including colliders, rigidbodies, and collision detection
* Take a project from an empty scene to a complete, playable game
